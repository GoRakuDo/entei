## Default Permission

Default permissions for the subtitles plugin: native subtitle parsing, media filename parsing and LazySync offset estimation.

#### This default permission set includes the following:

- `allow-subtitles-parse`
- `allow-subtitles-parse-filename`
- `allow-subtitles-estimate-lazy-sync`
