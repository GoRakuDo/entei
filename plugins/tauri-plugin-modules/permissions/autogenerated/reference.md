## Default Permission

Default permissions for native Jimaku and Nadeshiko API requests and Yomitan dictionary storage.

#### This default permission set includes the following:

- `allow-modules-jimaku-search-entries`
- `allow-modules-jimaku-search-entries-combined`
- `allow-modules-jimaku-entry-files`
- `allow-modules-jimaku-download-subtitle`
- `allow-modules-nadeshiko-search`
- `allow-modules-nadeshiko-segment-context`
- `allow-modules-nadeshiko-user-me`
- `allow-yomitan-import-dictionary`
- `allow-yomitan-list-dictionaries`
- `allow-yomitan-toggle-dictionary`
- `allow-yomitan-delete-dictionary`
- `allow-yomitan-find-terms`
- `allow-yomitan-find-kanji`
